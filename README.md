# Sibionics CGM Website

A responsive single-product e-commerce website for the Sibionics Continuous Glucose Monitor (CGM).

## Project Goals

- Present the product professionally.
- Educate visitors about CGM technology.
- Allow customers to purchase the product online.

## Features

- Responsive design
- Product page
- FAQ (Frequently Asked Questions)
- Blog
- Contact form
- Checkout flow (UI)

## Technologies

- HTML5
- CSS3
- JavaScript

## Planned Pages

- Home
- About
- Product
- FAQ
- Blog
- Contact
